# Architecture Decision Records (ADRs)

Cada decisão de arquitetura relevante do projeto fica registrada aqui, em um arquivo curto com Contexto, Decisão, Alternativas e Consequências ([formato de Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)).

Os ADRs não são reescritos. Quando uma decisão muda, um novo ADR substitui o antigo e o status do antigo passa a ser "Substituído".
